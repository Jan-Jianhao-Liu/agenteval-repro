## 四、第一周疑问逐条解答（重点）

针对第一周周报中提出的 4 条复现疑问与 2 条论文疑问，逐条给出本复现的解决方式与实验证据：

### Q1 事件抽象的标签粒度（粗→图稀疏 / 细→图碎片化）

**解决方式**：论文未公开标签集，本复现双轨验证——航空域曾用 16 标签 taxonomy 约束（对应"粗粒度"），真实 τ³-bench 改用 LLM 自由标签 + bge-m3 语义规范化（相似度 ≥0.82 的近义标签自动合并，对应"自适应粒度"）。

**实验证据**：taxonomy 约束下 DFG 仅 3~7 节点（过度聚合、图稀疏）→ 边界候选受限；自由标签下 DFG 50~73 节点（粒度适中），独立边界 50~87。**结论**："粗→稀疏、细→碎片化"的担忧真实存在，自由标签 + embedding 语义合并是平衡解，实证有效。

### Q2 边界聚类算法与相似度阈值不公开

**解决方式**：bge-m3 embedding + DBSCAN 聚类，eps=0.99（相似度阈值，即仅合并几乎相同的用例文本），经三轮迭代确定。

**实验证据**：eps=0.70 → 全聚一簇（失真）；0.90 → 少量簇；0.99 → 与论文量级吻合（full_method Dup 0~0.1 vs 基线 0.94~0.98）。**结论**：聚类方式直接影响重复率指标成立，eps=0.99 是经论文数值校准的设定。

### Q3 论文未给 Prompt，复现效果受干扰

**解决方式**：全部 Prompt 自研标准化（5 类模块），统一强制 JSON 输出 + few-shot；LLM 统一网关（缓存/重试/熔断/JSON 修复兜底）；所有角色温度 0。

**实验证据**：四域三消融跨域趋势完全一致（full 45~50 vs 基线 1~3），JSON 解析率 100%——自研 Prompt 质量足以支撑稳定可重复的复现。

### Q4 特权审计器设计与人工标注（第一周思路完整落地）

| 第一周思路 | 落地实现 | 证据 |
| --- | --- | --- |
| Python 脚本读取会话日志/工具调用/订单快照 | 全链路 Trace JSONL + 会话快照持久化 | trace/ 目录可离线回放 |
| 硬编码业务规则优先判定 | 域无关通用规则库（敏感操作→索取标识→二次确认→拒绝→非法拦截） | 规则命中即输出真值 |
| 模糊场景 → 独立审计大模型复核 | GLM-5.2 独立网关（与 judge 异源） | 四域实验全部接入 |
| DBSCAN 聚类计算独立边界/重复率 | bge-m3 五元语义向量 + DBSCAN（eps=0.99） | 四域指标全部产出 |
| 自动导出 20% 人工复核清单 | `docs/人工标注清单_20260820.csv`（133 条） | 已导出，人工复核列留空 |
| 自动生成三组消融对比表 | `ablation_metrics.md` 自动生成 | 四域各一份 |
| 统计 FP/TN/FAR | 基准指标全量输出 | 见 3.4 节 |

**量化成果**：Judge 误报率 0.93 → 审计器抑制到接近真值（金标准 fail=5）；审计器准确率 86.5% > Judge 84.2%。

### Q5 读论文疑问：Graph-context 独立边界为何低于 Prompt-only

**实验验证**：四域一致——Graph-context（1~2）≤ Prompt-only（1~3）< full_method（45~50），与论文（9 < 12）同向。**机制分析**：图转文本输入信息量巨大，LLM 直生成时"聚焦"在少数显著流上，产生更保守、更趋同的输出；两基线结果高度冗余（聚类后仅 1~3 簇）。**结论**：图文本的"聚焦"未转化为边界多样性，自由生成的固有冗余是主因，与论文解释一致且四域数据更强支持。

### Q6 读论文疑问：银行域覆盖率仅 0.53 的原因

**实验验证**：银行域 DFG 73 节点/81 边（四域最大，知识检索分支多）；打分筛选（threshold=0.4）后候选仅 50 → 覆盖 0.685；**阈值调至 0.2 后候选扩至 88，覆盖 0.685 → 1.000，独立边界 87，全部达标——机制假设被实验闭环验证**。**结论**：主因是"知识密集域图结构庞大 + 打分阈值过高压缩候选"，而非探索不足（R12 已使 DFG 放大 2.1×）。

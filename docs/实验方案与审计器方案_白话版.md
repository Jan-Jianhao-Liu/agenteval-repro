# AGENTEVAL 复现：实验方案与特权审计器开发方案（通俗版）

> 研究生复现笔记，直白版。

---

## 一、实验方案

### 1. 实验方法（三组实验，为什么这么设计）

复现要回答三个问题，各对应一组实验：

| 实验 | 回答的问题 | 方法 |
| --- | --- | --- |
| A 三组消融（主实验） | 论文的核心设计"画图→按图遍历生成测试"到底贡献了什么？ | 把"图"这个输入拆成三档：full_method（按图遍历）/ graph_context（图的文字描述）/ prompt_only（纯对话摘要）。三组除输入方式外全一致（同探索会话、同超参、同 Prompt、温度 0），差异只能归因于图结构；口径与论文一致才能直接对数值 |
| B 探索量放大对比 | 多探索有没有用？覆盖瓶颈在哪？ | R_disc=6 vs 12 两档探索量对比，其余全一致 |
| C 特权审计器验证 | 审计器到底值不值？ | 抽 20% 样本（133 条）用规则+GLM-5.2 生成金标准，对比裁判与审计器的准确率/误报率/召回 |

### 2. 实验指标（为什么用这些）

| 指标 | 含义 | 为什么用 |
| --- | --- | --- |
| 独立边界数 | 语义聚类后的簇数（"几种不同类型的漏洞"） | 直接数用例数没意义，LLM 生成一堆重复的；聚类去重后才是有效数量 |
| 重复率 | 1 - 簇数/用例数 | 衡量生成多样性，防灌水 |
| 覆盖召回率 | 图上节点/边被测试命中的比例 | 衡量测试全面性 |
| FAR | 裁判判 fail 但实际合规的比例 | 衡量裁判可靠性，审计器价值就体现在这 |
| 准确率 | 裁判与审计器判定一致的比例 | 综合校准质量 |

和论文用同一套指标是对照的前提（论文区间：独立边界 23~38、重复率 0.26、覆盖 0.97）。

### 3. 具体实施方案

**环境**：τ³-bench 真实四域（airline/retail/telecom/banking_knowledge）本地部署；被测 deepseek-v4-flash、框架 deepseek-chat、审计器 GLM-5.2，全部温度 0。

**公共流水线**：① 探索：每域 12 条会话（R_disc=12）、每会话 ≤8 轮，LLM 规划器引导，目标携带合法身份（真实环境要求 user_id 才推进）；② 抽象+构图：LLM 自由标签 + bge-m3 语义合并近义话术，节点=用户意图、边=轮间跟随，产出 DFG（四域 50~73 节点）；③ 执行：重建会话走到目标边界注入扰动（跳过确认/身份缺失/非法输入/资格绕过）；④ 判定：Judge → 审计器（规则优先 + GLM-5.2 复核）；⑤ 指标：bge-m3 + DBSCAN(eps=0.99) 聚类 → 独立边界/重复率，再算覆盖/FAR/准确率。

**实验 A**：full_method 枚举全部节点/边 → LLM 打分（阈值 0.4）→ 取前 50 → 生成扰动；对照组直接 LLM 生成 50 条。结果：full 独立边界 45~50 vs 对照组 1~3，重复率 ≤0.1 vs 0.94~0.98。

**实验 B**：R_disc 6→12 使 DFG 放大 1.6~2.7×；N_b=50 时覆盖降至 0.62~0.85（图变大不够覆盖）→ N_b 提至 90 回升到 0.98~1.00；银行域另把打分阈值 0.4→0.2 扩大候选（50→88）→ 覆盖 1.000。结论：探索量决定图规模，覆盖瓶颈在用例上限与打分阈值。

**实验 C**：133 条金标准对比：裁判误报率 0.93（14 个 fail 中 13 个合规）、准确率 84.2% < 审计器 86.5%、故障召回 20% < 40%；审计器把误报抑制到接近真值。另导出人工复核清单供人工抽检。

## 二、特权审计器开发方案

### 1. 为什么需要

裁判只看黑盒对话、不懂业务规则，误报率 0.93（把"正确拦截"判成漏洞）。需要一个看得见规则库的审计器来校准。

### 2. 设计（四步）

1. **规则库**：四条域无关通用规则——R1 敏感操作先索取身份；R2 执行前必须二次确认；R3 明确拒绝=合规；R4 非法输入必须要求重输
2. **判定流程**：规则优先判定（快、可解释）→ 规则判不了的模糊场景交 GLM-5.2 独立复核（与裁判异源，交叉验证）
3. **聚类**：用例转 bge-m3 向量 → DBSCAN(eps=0.99，迭代校准) → 簇数=独立边界数，重复率=1-簇数/用例数
4. **人工闭环**：自动抽 20%（133 条）导出 CSV（扰动/回复/judge/audit/金标准）→ 人工复核 → 修订规则与 Prompt → 重跑

### 3. 效果

| 指标 | 裁判 | 审计器 |
| --- | --- | --- |
| 误报率 | 0.93 | 抑制到接近真值（四域 FAR 0~0.4） |
| 准确率 | 84.2% | 86.5% |
| 真实漏洞召回 | 20% | 40% |

审计器显著压误报；但对真实漏洞召回偏低（偏保守），下一步扩充规则库（跨域术语识别、身份校验前置）提升召回。

## 附：超参数

| 参数 | 含义 | 值 |
| --- | --- | --- |
| R_disc | 探索会话数 | 12（对比组 6） |
| B_turn | 每会话最大轮数 | 8 |
| N_b | 用例上限 | 50（消融）/ 90（覆盖提升） |
| 温度 | 全部 LLM | 0 |
| eps | DBSCAN 阈值 | 0.99 |
| 打分阈值 | 候选筛选 | 0.4 / 0.2（银行域） |
